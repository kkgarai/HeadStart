Engineer Day Planner

One page for this shift, from now until logout. A run takes 10–15 minutes.

How to get started

  1. Load this folder in Chrome. It is the folder with manifest.json.
  2. Double-click the installer for this computer once: Install Mac.command, Install Windows.bat, or Install Linux.sh. That registers the local bridge. After that, the toolbar starts it.
  3. Click the toolbar icon. Paste your token once, then click Run Planner.
  4. Run it at the start of the shift, again mid-day, and again before logout. Each run picks up from now.

Update and uninstall

  • Update appears on the planner bar when a newer version is on the GitHub branch this copy follows. Click it. The extension reloads from that version. Done marks stay.
  • Uninstall is a file in the same folder, not a button on the page: Uninstall Mac.command, Uninstall Windows.bat, or Uninstall Linux.sh. It stops this copy's bridge and removes the host, its snapshots, and its cache. Then remove Engineer Day Planner in chrome://extensions. The cloned folder stays.

What is on the page

  • Needs us now — burning work. High urgency, the customer is blocked, and the next step is ours.
  • Follow-up due — a public update is owed. Quiet past the hold.
  • Still watching — peek only. Not due a follow-up.
  • Quick wins — under a few minutes. Batch these first.
  • GUS — investigations you follow or own as Support Contact, plus LAP on your cases.
  • Slack and Mail — what still needs your reply. Mark one Done and the next run leaves it off the page.
  • Customer asked for a meeting — they asked to meet, in a comment or an email.
  • Today's plan — the shift in time, through logout. Open time is the dotted gap.
  • Before you log off — a close you already promised for today.
  • Tomorrow, first thing — a close you already promised for the next working day.

Each case line shows severity, status, and when you last posted an update. A new case, or a case with no update from you, says so.

Help opens the guide. Feedback opens the form. Logs is the run log. Copy it when you report an error.
